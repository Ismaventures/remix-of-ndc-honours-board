## RECOMMENDATIONS FOR DATA ENTRY

### Option 1: Create Separate Records Per Course
- Each person listed in a course gets their own record
- Allows tracking role changes and rank progression
- Best for historical accuracy
- Will create duplicates but maintains temporal context

### Option 2: Single Record With Course History
- One person = one record
- Decoration field shows all courses attended
- Simplifies database but loses role/rank details per course

### Option 3: Hybrid Approach
- Multiple records only for people with significant rank/role changes
- Single records for one-time appearances
- Balances accuracy with data simplicity
